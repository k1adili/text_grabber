# متن‌خوان تصویر و PDF

برنامهٔ دسکتاپ OCR با رابط گرافیکی فارسی، مبتنی بر Tesseract OCR.

## امکانات

- استخراج متن از فایل‌های تصویری مانند PNG، JPG، BMP، TIFF و WebP
- استخراج متن از تمام صفحه‌های PDF، از جمله PDFهای اسکن‌شده
- انتخاب و عکس‌برداری از بخشی از صفحه و تبدیل متن همان ناحیه
- انتخاب زبان OCR (پیش‌فرض: فارسی و انگلیسی)
- کپی متن یا ذخیرهٔ آن به‌صورت فایل UTF-8

## راه‌اندازی در ویندوز

1. Python 3.10 یا جدیدتر را نصب کنید.
2. Tesseract OCR را نصب کنید و هنگام نصب، دادهٔ زبان فارسی (`fas`) و انگلیسی (`eng`) را انتخاب کنید. اگر Tesseract در `PATH` نیست، مسیر `tesseract.exe` را در برنامه تنظیم کنید.
3. در پوشهٔ پروژه اجرا کنید:

   ```powershell
   py -m pip install -r requirements.txt
   py main.py
   ```

برای OCR فارسی و انگلیسی، زبان برنامه را روی `fas+eng` بگذارید. برای زبان‌های دیگر، کد زبان نصب‌شده در Tesseract را وارد کنید.
